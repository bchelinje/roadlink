# BeC OpenId Connect - Documentation

This folder contains comprehensive documentation for the BeC Moving Services platform.

## Documentation Files

### 1. [GOOGLE_MAPS_AND_PRICING.md](./GOOGLE_MAPS_AND_PRICING.md)
Complete guide for Google Maps integration and Dynamic Pricing system.

**Topics covered:**
- Google Maps API integration (geocoding, distance calculation, routing, autocomplete)
- Dynamic pricing calculator with 7 rule types
- Real-time driver location tracking
- ETA calculations
- API endpoints reference
- Configuration and setup
- Usage examples and troubleshooting

### 2. [MIGRATION_INSTRUCTIONS.md](./MIGRATION_INSTRUCTIONS.md)
Database migration guide for SignalR, Hangfire, and Email features.

**Topics covered:**
- Running EF Core migrations
- Setting up Hangfire dashboard
- Email service configuration
- Troubleshooting migration issues

### 3. [NEW_ENDPOINTS_SUMMARY.md](./NEW_ENDPOINTS_SUMMARY.md)
Comprehensive summary of all 77 new API endpoints.

**Topics covered:**
- Customers endpoints (10 endpoints)
- Reviews endpoints (8 endpoints)
- Vehicles endpoints (13 endpoints)
- Documents endpoints (12 endpoints)
- Notifications endpoints (18 endpoints)
- Payments endpoints (16 endpoints)
- Complete request/response examples
